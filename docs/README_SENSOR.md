# CloudOps Intel — Lab PC Sensor Agent Package
**Version:** 1.0.0  
**Environment:** Windows 10 / Windows 11 / Windows Server  
**Transport:** Strict Mutual/Verified HTTPS on Port 8443  

---

## 1. Prerequisites
- Windows 10/11 x64
- Python 3.10+ installed and on system PATH
- Network connectivity to the CloudOps Intel server (Port 8443)
- An active, single-use Enrollment Code generated by a Super Admin in the CloudOps Intel Web Dashboard (`Device Management` -> `Generate Enrollment Code`)

---

## 2. Fast Installation (Interactive or Automated)

Open an **Elevated Administrator PowerShell** prompt in this extracted directory:

```powershell
# Run the automated installer
powershell -ExecutionPolicy Bypass -File .\install_sensor_client.ps1 `
    -ServerUrl "https://<SERVER_IP_OR_DNS>:8443" `
    -EnrollmentCode "<SUPER_ADMIN_ENROLLMENT_CODE>"
```

### What Happens During Installation:
1. The installer copies the sensor agent binaries into `C:\ProgramData\CloudOpsIntel\Sensor`.
2. Secure NTFS ACLs are configured (SYSTEM & Administrators only).
3. The sensor securely contacts the server using `root.crt` to submit an enrollment request with the local Windows hostname and hardware UUID.
4. The sensor pauses and awaits **Super Admin review & approval** in the CloudOps Intel Dashboard.
5. In the dashboard, the Super Admin assigns the PC location (e.g. Lab 1, Room 204, PC 12) and clicks **Approve**.
6. The sensor receives its unique, revocable `ak_lab_...` credential and saves it to `sensor_config.json`.
7. A Windows Scheduled Task (`CloudOpsSensorAgent`) is registered to start automatically at system boot under `NT AUTHORITY\SYSTEM` without requiring any user logon.

---

## 3. Verifying Sensor Operation

Check the local sensor status:
```powershell
schtasks /Query /TN "CloudOpsSensorAgent" /V /FO LIST
```

Inspect local SQLite telemetry queue:
The sensor stores unsent metrics locally in `C:\ProgramData\CloudOpsIntel\Sensor\sensor_spool.db` during network outages for up to 24 hours.

---

## 4. Uninstallation

To cleanly remove the sensor:
```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall_sensor_client.ps1
```

If the server is reachable, the sensor will notify the server and request retirement. If offline, the uninstaller will display a prominent warning reminding the Super Admin to confirm retirement in the web dashboard.
